# 10. 混合架构：Mamba/SSM + 注意力

## 两种记忆模型

| | 注意力 (Transformer) | SSM (Mamba) |
|---|---|---|
| 记忆方式 | 全量回顾: KV Cache存所有历史 | 压缩快照: 历史压进固定大小状态 |
| 计算复杂度 | O(T²) | O(T) |
| 推理显存 | 随T线性增长 | 恒定 |
| 精确检索 | 强 (能定位"第几行第几个字") | 弱 (快照有损) |

## 状态空间模型 (SSM)

离散递推形式：

```
h_t = Ā ⊙ h_{t-1} + B̄·x_t    # 更新状态: 衰减旧信息, 写入新信息
y_t = C·h_t                    # 读出
```

状态 h 只有 d_model × d_state 维——这就是"恒定显存、线性计算"的根源。

### Mamba的"选择性"

经典SSM(S4)的A/B/C是固定矩阵 → 对所有输入一视同仁。
Mamba让 Δ、B、C 由输入投影决定 → 模型学会"记什么、忘什么"：

- Δ大 → Ā→0 → 丢弃旧状态（忘）
- Δ小 → Ā→1 → 保留历史（记）

训练用并行扫描（selective scan）保持可并行，推理每步O(1)。

## 为什么混合

纯SSM的短板是精确检索（needle-in-a-haystack类任务会翻车——
快照记不住细节）；纯注意力长上下文成本高。解法：
**Mamba层为主 + 少量注意力层做"锚点"**，兼顾吞吐和检索精度。

## 里程碑

| 模型 | 时间 | 要点 |
|------|------|------|
| Mamba-1 | 2023.12 | 选择性SSM + 硬件感知扫描 |
| Jamba | 2024.3 | 首个生产级混合（注意力:Mamba≈1:7） |
| Mamba-2 | 2024.5 | SSD对偶: SSM与注意力的数学联系, 训练快2-8x |
| Kimi Linear | 2025 | 混合线性注意力, 长上下文降本 |
| Nemotron 3 | 2026 | MoE+Mamba-2+注意力锚点, 1M上下文, 吞吐最高7.5x |
| Mamba-3 | 2026.3 | 指数梯形离散化+复数状态+MIMO, 长序列延迟1/7 |

Mamba-3的三招：二阶精度的指数梯形离散化（短卷积变可选）、复数值状态
（补逻辑推理短板）、MIMO机制（榨干解码时的GPU利用率）。
