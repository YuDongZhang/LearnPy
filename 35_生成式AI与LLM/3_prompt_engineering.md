# 3. Prompt 工程

## 什么是 Prompt 工程

**Prompt 工程**是设计有效提示词以获得更好结果的技术，是与 LLM 高效交互的艺术。

为什么重要：决定模型输出质量、激发模型潜在能力、降低成本。

核心要素：清晰明确的指令、合理的上下文、适当的约束。

## 基本原则

| 原则 | 反例 ✗ | 正例 ✓ |
|------|--------|--------|
| 清晰明确 | 写点什么 | 写一篇500字关于AI的文章 |
| 具体化 | 写一首诗 | 写一首关于春天的七言绝句 |
| 结构化 | 混乱堆砌 | 用 ```、---、XML标签分隔内容 |
| 提供上下文 | （缺失） | 背景信息、目标受众、使用场景 |

## System Prompt

设置 AI 角色和行为，全局指令、持久生效：

```
你是一个专业的Python开发者，擅长编写高效、可维护的代码。

规则:
1. 代码必须符合PEP 8规范
2. 添加适当的注释
3. 优先使用类型提示
4. 包含单元测试
```

最佳实践：简洁明确、列出具体规则、适当示例。

## Few-shot 学习

提供少量示例帮助模型理解任务：

```
例1: 苹果 -> 水果
例2: 胡萝卜 -> 蔬菜
例3: 牛肉 -> ?
```

技巧：2~5 个示例、保证示例多样性、输入输出格式一致。

## Chain-of-Thought（思维链）

让模型展示推理过程，提升复杂问题回答质量：

```
问题: 小明有5个苹果，小红给了他3个，小明吃了2个，还剩多少?

思考过程:
1. 小明原有5个苹果
2. 小红给了3个，现在有5+3=8个
3. 小明吃了2个，剩下8-2=6个
答案: 6个
```

变体：**零样本 CoT**（加一句"让我们一步步思考"）、**自洽性 CoT**（多次采样取多数答案）。

## ReAct 模式

结合**推理 (Reason)** 和**行动 (Act)**，动态决策、使用工具：

```
思考: 我需要查一下北京今天的天气
行动: 调用天气API
观察: 北京今天晴，25度
思考: 现在我知道天气了，可以给用户建议
...
```

## 角色扮演

让 AI 扮演特定角色，获得更专业的回答：

```
角色定义: 你是一位拥有20年经验的资深软件架构师，
曾在Google、Microsoft等公司工作。

任务: 请帮我review这段Python代码，指出可能的性能和架构问题。

[代码]
```

技巧：详细描述角色背景、明确专业领域、指定输出风格。

## 输出格式控制

```json
// 指定JSON格式
{
  "name": "姓名",
  "age": 年龄,
  "skills": ["技能1", "技能2"]
}
```

- **结构化输出**：按 `## 优点` / `## 缺点` 等固定结构回答
- **模板填充**：请填写以下模板：[主题]是一个[形容词]的[名词]，主要特点是[特点1]和[特点2]。

## 复杂任务分解

- **逐步引导**：第一步分析问题 → 第二步列出要点 → 第三步详细展开 → 第四步总结归纳
- **思维树 (ToT)**：多个思考分支，探索评估后回溯选择
- **自我反思**：执行任务 → 检查结果 → 修正 → 最终输出

## 约束条件

| 类型 | 示例 |
|------|------|
| 长度 | 不超过500字、正好3段、列出5点 |
| 风格 | 正式/口语化、技术/通俗、中文/英文 |
| 内容 | 只包含事实、适合儿童 |
| 格式 | 使用Markdown、代码用反引号、列表用序号 |

## 迭代优化

分析结果哪里不满意 → 调整 prompt 长度/表述/示例/约束 → 再次尝试：

```
第一次: 写一首诗                     → 不满意
第二次: 写一首关于春天的七言绝句，要押韵   → 好一点
第三次: ...要押韵，包含"春风"、"花开"意象 → 符合要求
```

## 常见错误

| 错误 | 反例 ✗ | 正例 ✓ |
|------|--------|--------|
| 模糊不清 | 写好一点 | 增加具体例子，语言更生动 |
| 过于复杂 | 同时要求10个功能 | 每次一个功能，逐步完成 |
| 忽略约束 | 写快点 | 在30秒内完成 |
| 缺乏上下文 | 解释这个词 | 在计算机科学语境下解释这个词 |

## 实用模板

```
问答模板:  角色 + 背景 + 问题 + 格式
创作模板:  主题 + 类型 + 风格 + 长度 + 要点
评估模板:  评估内容 + 维度 + 评分标准 + 输出格式
```

## LangChain 应用

```python
from langchain.prompts import PromptTemplate
from langchain.chains import LLMChain

template = """你是一个{role}。
请用{style}风格回答以下问题:
问题: {question}

要求:
1. 长度: {length}
2. 格式: {format}
"""

prompt = PromptTemplate(
    template=template,
    input_variables=["role", "style", "question", "length", "format"]
)

chain = LLMChain(llm=llm, prompt=prompt)
result = chain.run(role="Python专家", style="技术博客",
                   question="什么是装饰器?", length="500字",
                   format="Markdown")
```
