| 对比项 | 传统机器学习 | 深度学习 |
|--------|-------------|---------|
| 特征提取 | 人工提取 | 自动学习 |

## 核心概念（详解）

这一节把深度学习的四个核心零件掰开讲：**全连接层**（怎么算）、**激活函数**（为什么必须有）、**损失函数**（怎么衡量错）、**优化器**（怎么改参数）。下面的数字都来自 `1_dl_overview.py` 的真实运行输出，可以对照着看。

### 1. 全连接层：神经网络的运算单元

一个"神经元"只做三件事：**加权求和 → 加偏置 → 过激活函数**。

```
y = f(w₁x₁ + w₂x₂ + ... + wₙxₙ + b) = f(Wx + b)
```

| 符号 | 含义 |
|------|------|
| x | 输入向量（一张图片的像素、一个人的年龄收入等） |
| W | 权重矩阵，**模型要学的参数** |
| b | 偏置，**模型要学的参数** |
| Wx + b | 线性变换（加权求和） |
| f | 激活函数，引入非线性 |

**手算一遍**：输入 `x = [1, 2]`，权重 `w = [0.5, -0.3]`，偏置 `b = 0.1`

```
w·x + b = 0.5×1 + (-0.3)×2 + 0.1 = 0.5 - 0.6 + 0.1 = 0.0
过 ReLU → 0.0
```

"全连接"的意思是：**这一层的每个输出，都和前一层所有输入相连**。所以参数量 = `输入数 × 输出数 + 输出数`。

对照代码中的 `nn.Linear(784, 256)`：`784×256 + 256 = 200,960` 个参数，和脚本输出的 fc1 参数量完全一致。

### 2. 激活函数：没有它，10 层网络等于 1 层

**这是深度学习最关键的认知**。如果每层只有线性变换，多层叠加起来仍然是线性的：

```
y = W₂(W₁x + b₁) + b₂ = (W₂W₁)x + (W₂b₁ + b₂) = W'x + b'
```

不管叠多少层，都能被一个 `W'x + b'` 等价替代 —— 10 层和 1 层没有任何区别，根本无法拟合复杂曲线。所以每层线性变换之后，必须加一个**非线性**函数。

输入 `[-2, -1, 0, 1, 2]` 时，四个常用激活函数的真实输出：

| 函数 | 公式 | 取值范围 | 特点 |
|------|------|---------|------|
| Sigmoid | 1/(1+e⁻ˣ) | (0, 1) | 输出像概率；两端梯度趋近 0，深层网络易**梯度消失** |
| Tanh | (eˣ-e⁻ˣ)/(eˣ+e⁻ˣ) | (-1, 1) | 零点对称，比 Sigmoid 好，仍有梯度消失问题 |
| ReLU | max(0, x) | [0, +∞) | **最常用**：计算快，正区间梯度恒为 1，缓解梯度消失 |
| Softmax | eˣⁱ / Σeˣʲ | (0,1) 且和为 1 | 只用在**输出层**，把得分变成概率 |

```
Sigmoid: [0.1192, 0.2689, 0.5,    0.7311, 0.8808]
Tanh:    [-0.964, -0.7616, 0.0,   0.7616, 0.964]
ReLU:    [0.0,    0.0,    0.0,    1.0,    2.0]     ← 负数全变 0
```

**Softmax 的意义**：把 [1, 2, 3] 这样的"得分"变成 [0.09, 0.2447, 0.6652] —— 三个数加起来等于 1，可以理解为"属于各类别的概率"，其中第 3 类最大（0.6652）。

**选型口诀**：隐藏层用 ReLU（或 GELU），二分类输出用 Sigmoid，多分类输出用 Softmax。

### 3. 损失函数：把"错得多离谱"变成一个数

训练需要知道"现在有多差"才能改进，损失函数就是这个打分器。它还有一个硬性要求：**必须可导**，因为后面要靠它算梯度。

**MSE 均方误差（回归任务）**

```
MSE = (1/n) × Σ(y_predᵢ - y_trueᵢ)²
```

手算：预测 `[2.5, 0, 2]`，真实 `[3, 0, 2]`

```
(2.5-3)² = 0.25    (0-0)² = 0    (2-2)² = 0
求和 = 0.25  →  除以 3  →  MSE = 0.0833
```

平方的作用：让正负误差都变成正数，同时**放大大误差**（错得越多惩罚越重）。

**CrossEntropy 交叉熵（分类任务）**

简化形式：`CE = -log(正确类别的预测概率)`

手算：得分 [1, 2, 3] 经 Softmax 得到 [0.09, 0.2447, 0.6652]，真实类别是 2（第 3 个）

```
CE = -log(0.6652) = 0.4076
```

直观理解：正确类别的概率越接近 1，`-log` 越接近 0（损失小）；概率越接近 0，损失急剧变大（严厉惩罚）。

**为什么分类不用 MSE？** Softmax + MSE 会出现"预测错时梯度反而很小"的情况，学得极慢；交叉熵的梯度形式是 `(预测概率 - 真实值)`，错得越多梯度越大，收敛更快。

**BCE 二元交叉熵**：二分类专用，配合 Sigmoid 使用。

### 4. 优化器：怎么把损失降下去

**梯度下降的直觉**：把损失想象成山谷的高度，参数就是你的位置。**梯度**指向当前位置最陡的**上坡**方向，所以往**反方向**走就是下坡。

```
w ← w - lr × ∂Loss/∂w
```

| 符号 | 含义 |
|------|------|
| lr | 学习率，每步走多远（**最重要的超参数**） |
| ∂Loss/∂w | 损失对参数的梯度，告诉方向 |

学习率的影响：太大 → 一步跨过谷底，来回震荡甚至发散；太小 → 走得太慢，训练没完没了。

常见优化器对比：

| 优化器 | 思路 | 适用 |
|--------|------|------|
| SGD | 最朴素的梯度下降 | 简单，收敛慢，需仔细调 lr |
| SGD + Momentum | 累积历史梯度方向，像下坡有惯性 | 减少震荡 |
| Adam | 每个参数自适应不同学习率 + 动量 | **最常用**，默认好用 |
| AdamW | Adam + 正确的权重衰减 | Transformer 等场景常用 |
| RMSprop | 按梯度平方的滑动平均缩放学习率 | RNN 常用 |

**选择建议**：不确定就用 `Adam(lr=1e-3)`，这是绝大多数场景的安全默认值。

### 串起来看

一次训练迭代的完整链条：

```
前向传播 → 算出预测 → 损失函数 → 算出"错多少" → 反向传播 → 算出每个参数的梯度 → 优化器 → 按梯度更新参数
```

循环往复，损失持续下降，参数逐步逼近最优解。`1_dl_overview.py` 第 5 节用 `y = 2x + 1` 演示了这个过程：损失从 `0.5705` 一路降到接近 `0`，最终学到的参数 `w = 2.000, b = 1.000`，正好是真实规律 —— 这就是训练的全部本质。

## 训练流程

```
1. 数据准备     → 加载、增强、批量处理
2. 模型构建     → 定义网络结构、初始化参数
3. 训练循环     → 前向传播 → 计算损失 → 反向传播 → 更新参数
4. 模型评估     → 验证集评估、超参数调整
5. 模型保存/部署 → 保存权重、导出模型
```

训练循环伪代码：

```python
for epoch in range(num_epochs):
    for batch in dataloader:
        outputs = model(inputs)        # 前向传播
        loss = criterion(outputs, labels)

        optimizer.zero_grad()          # 清零梯度
        loss.backward()                # 反向传播
        optimizer.step()               # 更新参数
```
