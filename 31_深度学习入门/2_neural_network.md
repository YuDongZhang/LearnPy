# 2. 神经网络基础与原理

## 从生物神经元到人工神经元

生物神经元：树突接收信号 → 细胞体处理 → 轴突传递信号。

人工神经网络对应：

| 生物 | 人工 |
|------|------|
| 树突接收信号 | 输入 |
| 突触强度 | 权重 |
| 是否激活 | 激活函数 |
| 轴突输出 | 输出 |

人脑约有 860 亿个神经元，深度学习网络有数百万到数千亿个参数。

## 感知机

最简单的神经网络——单层感知机：

```
     x1 ──┐
          │
     x2 ──┼──→ ● ──→ y
          │
     x3 ──┘
```

公式：`y = f(w1*x1 + w2*x2 + w3*x3 + b)`

- w: 权重 (weight)
- b: 偏置 (bias)
- f: 激活函数

局限：感知机只能处理线性可分问题。

## 多层神经网络

多层感知机 (MLP)：输入层 → 隐藏层 → 输出层，全连接层每一层都连接到下一层所有节点。

```
     输入层     隐藏层     输出层
       x1 ──► h1 ──► y1
       x2 ──► h2 ──► y2
       x3 ──► h3 ──►
```

前向传播：`h1 = f(W1*x + b1)`，`y = W2*h1 + b2`

反向传播：计算梯度并更新参数。

## 激活函数

为什么需要激活函数？引入非线性。没有激活函数，多层网络退化为线性组合，毫无意义。

| 激活函数 | 公式 | 输出范围 | 特点 |
|---------|------|---------|------|
| Sigmoid | 1/(1+e^-x) | (0, 1) | 梯度消失 |
| Tanh | tanh(x) | (-1, 1) | 梯度消失 |
| ReLU | max(0, x) | [0, ∞) | 计算快，最常用，神经元死亡问题 |
| Leaky ReLU | max(0.01x, x) | (-∞, ∞) | 解决神经元死亡 |
| Softmax | - | 概率分布 | 多分类输出层 |

## 损失函数

损失函数衡量模型预测与真实值的差距：

1. **均方误差 (MSE)** — 回归：`L = (1/n) * Σ(y_pred - y_true)²`
2. **交叉熵 (CrossEntropy)** — 分类：`L = -Σ y_true * log(y_pred)`；二分类：`L = -[y*log(p) + (1-y)*log(1-p)]`
3. **Hinge Loss** — SVM：`L = max(0, 1 - y*pred)`

选择原则：回归 → MSE，二分类 → BCE，多分类 → CrossEntropy。

## 反向传播

反向传播用链式法则计算梯度：

```
∂L/∂w = ∂L/∂y * ∂y/∂z * ∂z/∂w
```

步骤：

1. 前向传播：计算输出和损失
2. 计算输出层梯度
3. 反向传播：逐层计算梯度
4. 更新参数

梯度下降：`w = w - learning_rate * gradient`

## 优化器

| 优化器 | 思路 | 特点 |
|--------|------|------|
| SGD | w = w - lr * gradient | 收敛慢，易陷局部最优 |
| Momentum | 累积速度 | 加速收敛 |
| AdaGrad | 自适应学习率 | 学习率越来越小 |
| RMSprop | 指数加权平均 | 适合非平稳目标 |
| Adam | Momentum + RMSprop | 收敛快、稳定，最常用 |

Adam 默认参数：lr=0.001, beta1=0.9, beta2=0.999。

## 正则化

防止过拟合的技术：

1. **L1 正则化**：`L = Loss + λ|w|`，产生稀疏权重（特征选择）
2. **L2 正则化**：`L = Loss + λw²`，权重衰减
3. **Dropout**：训练时随机"关闭"部分神经元
4. **Early Stopping**：验证集性能下降时停止训练
5. **Data Augmentation**：数据增强

## 超参数

| 超参数 | 要点 |
|--------|------|
| 学习率 | 最重要！太大不收敛，太小收敛慢；常用 0.001、0.0001 |
| Batch Size | 常用 32/64/128/256；小批量泛化好噪声大 |
| 网络层数 | 太浅欠拟合，太深梯度消失/爆炸 |
| 隐藏单元数 | 一般 64/128/256/512 |
| Epochs | 太多过拟合，配合早停 |

## 梯度问题

**梯度消失**：链式乘法导致梯度指数衰减，前面层无法学习。解决：ReLU、BatchNorm、残差连接。

**梯度爆炸**：梯度指数增长，训练不稳定。解决：梯度裁剪。

**批归一化 (BatchNorm)**：归一化每层输入，加速训练、稳定梯度：`y = (x - μ)/σ * γ + β`

**残差连接**：跳跃连接 `y = F(x) + x`，ResNet 核心思想，解决深层网络训练问题。

## 训练技巧

- 数据预处理：归一化/标准化、处理缺失值
- 权重初始化：Xavier、He 初始化
- 学习率调度：Step LR、Cosine Annealing、Reduce on Plateau
- 调试：先小数据集验证代码、检查梯度流、TensorBoard 可视化
- Ensemble：多模型投票
